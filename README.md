# LABUBU 宇宙创作站

一个为 Codex 桌面界面设计的暖象牙色 × 腮红粉主题，把工作区变成柔和、明亮又有一点工作室气质的创作空间。

![LABUBU 宇宙创作站预览](assets/artwork.webp)

## 这个项目是什么

这是一个本地优先的 Codex 桌面主题作品，重点放在三件事：

- 用暖象牙、奶油、腮红和珊瑚色建立统一的视觉语言；
- 保留原生导航、控件、焦点状态和交互语义；
- 通过右侧插画、左侧阅读保护层和高对比文字，让装饰感不牺牲可读性。

## 亮点

- **Editorial showcase 布局**：适合展示型首页，同时兼顾长文本阅读。
- **语义化配色**：背景、表面、文字、边框、焦点、成功和警告状态分别定义。
- **本地背景素材**：使用仓库内的 WebP 预览图，不依赖外部图片服务。
- **本地一键启动边界清晰**：主题本体可公开复用；机器专用的一键启动器不随仓库分发。
- **可读性优先**：主题设计保留原生控件与键盘焦点，并以截图对比作为发布前检查的一部分。

## 快速开始

本项目面向已经安装 Codex Desktop、Node.js 和本地主题切换运行环境的 Windows 用户。

1. 将主题目录放入你的 Codex 主题目录。
2. 确认 `theme.json`、`theme.css` 和 `assets/artwork.webp` 位于同一主题目录。
3. 通过本地主题切换器应用 `labubu-universe-studio`。
4. 如果需要一键启动，请为自己的 Codex 安装单独准备并审核启动器。

主题核心文件：

```text
theme.json                         # 主题元数据、调色板和设计约束
theme.css                          # 视觉样式与原生语义映射
assets/artwork.webp                # 本地背景插画
launcher/README.md                # 说明机器专用启动器为何不公开
```

## 兼容性与边界

- 当前公开包按 **Windows + Codex Desktop** 场景整理。
- 主题注入属于本地运行时行为；完整退出 Codex 后，运行时注入会消失，需要重新应用。
- 机器专用的一键启动器不随公开仓库分发，以避免暴露本机路径、运行状态位置和信任边界。
- 仓库不包含 Codex 安装包、账号信息、凭据或任何自动安装逻辑。
- 未承诺 macOS、Linux 或其他桌面客户端的兼容性。

## 设计取舍

这个主题的目标不是覆盖应用本身，而是在保留原生功能和状态的前提下，增加一个有辨识度的视觉层。因此，项目刻意不修改应用安装包，也不替换原生交互流程。
